# Cartas — Reinos do Destino

Protótipo digital jogável em português, inspirado no baralho medieval personalizado. **Versão experimental 1.1.**

## Jogar
Abra [index.html](index.html) em um navegador moderno ou habilite GitHub Pages em **Settings → Pages → Deploy from a branch → main / root**.

## Incluído
- Jogo solo contra adversário automatizado.
- Baralho compartilhado de 38 cartas (2–10 dos quatro naipes + dois Coringas), sem duplicatas.
- Três heróis por lado, Vida, Defesa, Energia, escudos, cartas na mão e descarte.
- Ataque, cura, geração de Energia, escudos, Ases por afinidade e Pontos de Glória.
- Registro de ações durante a partida e interface adaptável a celular.

## Limitações desta primeira entrega
É um **protótipo funcional, não uma implementação definitiva**. Oponentes usam IA simples. Os Coringas têm efeitos digitais provisórios e ainda precisam ser alinhados às descrições completas. A distribuição inicial dos heróis é fixa, sem draft. As imagens finais das cartas ainda não foram integradas. O descarte do Ás de Espadas é automático; será substituído por escolha do jogador. Não há persistência nem multiplayer.
