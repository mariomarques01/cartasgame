# Artes dos botões

Envie nesta pasta os dois arquivos PNG anexados na conversa, com os nomes exatos:

- `Atacar.png` — botão vermelho com espadas cruzadas.
- `Defender.png` — botão azul com escudo dourado.

O script `godot/scripts/main.gd` detecta automaticamente `res://assets/ui/Atacar.png` e `res://assets/ui/Defender.png` e os aplica aos botões de ação. Se faltarem, mantém os botões padrão.
